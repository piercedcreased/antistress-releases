# Antistress downloads

Builds of a personal, non-commercial relaxation-toys app (a fan clone made for fun; play money only, nothing to buy).

Get the latest version from **[Releases](https://github.com/piercedcreased/antistress-releases/releases/latest)**:

- **Android:** download the `.apk` on your phone and open it (allow installing from your browser if asked). New versions install over the old one; your progress is kept.
- **Windows:** download the PC `.zip`, unzip it and run `Antistress.exe`.

Sounds and textures are CC0 (Kenney, OpenGameArt, Poly Haven, ambientCG).
